# 电商智能定价决策引擎 — 项目设计文档

> **项目名称**：PriceWise — 电商智能定价决策引擎  
> **创建日期**：2026-06-01  
> **版本**：v1.0  
> **目标岗位**：数据分析师 / 数据工程（双方向）  
> **技术栈**：Java + Spring Boot + Spark + ECharts  

---

## 一、项目定位

### 1.1 一句话描述

一个基于真实电商数据的智能定价分析平台，从价格弹性建模、竞品生态位画像、品类波士顿矩阵诊断到交互式 What-If 调价模拟，**从"描述现状"升级到"指导决策"**。

### 1.2 核心差异化

| 市面常见项目 | 本项目的区别 |
|-------------|-------------|
| 只做可视化看板 | 看板 + **交互式决策模拟器** |
| 静态数据分析 | **动态弹性建模** + 策略推演 |
| 单一维度分析 | 弹性/竞品/品类/模拟 **四模块联动闭环** |
| 忽略安全性 | **分层安全设计**（脱敏/鉴权/审计） |

### 1.3 面试叙事主线

> "我们发现 A 品类的价格弹性系数是 2.3，当前定价偏高，处于波士顿矩阵的'问题象限'。通过 What-If 模拟，降价 12% 预计销量提升 27%，毛利总额增长 8.5%。系统给出的策略建议是'渗透定价，抢占市场份额'。"

## 三、核心功能模块

### 模块 1：价格弹性分析引擎

**功能描述**：量化不同品类/SKU 的价格敏感度

| 项目 | 说明 |
|------|------|
| **模型** | Spark ML 对数线性回归：`ln(销量) = α + β × ln(价格) + 控制变量` |
| **输入** | 历史订单数据（价格、销量、时间、品类） |
| **输出** | 每个品类的弹性系数 β（绝对值 >1 = 弹性高） |
| **ECharts** | 品类弹性系数柱状图 + 价格-销量散点拟合曲线 |

### 模块 2：竞品价格生态位画像

**功能描述**：构建价格-评分-销量三维空间，定位自身与竞品的生态位

| 项目 | 说明 |
|------|------|
| **竞品来源** | 同一品类下的不同 Seller 视为竞品（Olist 数据集天然优势） |
| **分析维度** | 价格 × 评分 × 销量 三维定位 |
| **输出** | 生态位归属（高质高价区 / 性价比区 / 低价冲量区） |
| **ECharts** | 3D 气泡图 + 价格带分布热力图 |

### 模块 3：品类波士顿矩阵诊断

**功能描述**：自动将品类映射到波士顿矩阵，并展示迁移轨迹

| 项目 | 说明 |
|------|------|
| **分类逻辑** | 金牛(高份额低增长) / 明星(高份额高增长) / 问题(低份额高增长) / 瘦狗(低份额低增长) |
| **动态追踪** | 按季度计算各品类位置，展示迁移路径 |
| **输出** | 品类健康度综合评分卡（销量趋势 + 毛利率 + 退货率 + 关联带动） |
| **ECharts** | 四象限散点气泡图 + 轨迹线 + 评分雷达图 |

### 模块 4：What-If 调价模拟器 ⭐ 核心亮点

**功能描述**：交互式工具，输入调价方案 → 预测结果 → 给出建议

| 项目 | 说明 |
|------|------|
| **输入** | 选择品类/SKU + 调价幅度（-30% ~ +30%） |
| **计算** | 弹性模型预测销量变化 → 毛利变动 → 利润影响 |
| **输出** | 建议标签（推荐调价 / 谨慎操作 / 不建议） |
| **ECharts** | 利润影响瀑布图 + 损益平衡线 + 方案对比表 |

## 四、安全设计（分层防护）

### 4.1 数据层安全

| 措施 | 实现方式 | 防护目标 |
|------|---------|---------|
| PII 脱敏 | 客户ID → SHA256 哈希，GPS坐标 → 城市级别，支付金额 → 区间分桶 | 隐私保护 |
| 静态加密 | MySQL InnoDB 表空间加密，敏感字段 AES-256 | 数据泄露 |
| 最小权限 | Spark 作业专用数据库账号，仅授予必要表/字段权限 | 越权访问 |

### 4.2 应用层安全

| 措施 | 实现方式 | 防护目标 |
|------|---------|---------|
| JWT 认证 | 登录签发 Token，每次请求 Authorization Header 携带 | 身份伪造 |
| RBAC 授权 | 管理员(全量数据) / 分析师(聚合数据) 双角色 | 越权访问 |
| API 限流 | Guava RateLimiter，100次/分钟/IP | 暴力攻击 |
| 注入防护 | PreparedStatement + 输入校验 + XSS Filter | SQL注入/XSS |

### 4.3 审计与前端安全

| 措施 | 实现方式 | 防护目标 |
|------|---------|---------|
| 操作日志 | AOP 切面记录：谁、何时、调用接口、入参摘要 | 事后追溯 |
| 前端脱敏 | 单品级金额模糊显示，聚合数据精确显示 | 屏幕信息泄露 |
| CSP 策略 | Content-Security-Policy Header 配置 | XSS 攻击 |
| 会话超时 | Token 30分钟过期，自动退出 | 会话劫持 |

## 六、数据源说明

### Olist Brazilian E-Commerce Dataset

| 数据集 | 记录数 | 关键字段 |
|--------|--------|---------|
| orders | ~100k | order_id, customer_id, order_purchase_timestamp, order_status |
| order_items | ~112k | order_id, product_id, seller_id, price, freight_value |
| products | ~33k | product_id, product_category_name, product_weight_g, product_length_cm |
| sellers | ~3k | seller_id, seller_city, seller_state |
| customers | ~96k | customer_id, customer_city, customer_state |
| reviews | ~100k | review_id, order_id, review_score, review_comment_message |

**竞争优势**：不同 Seller 在相同品类下形成天然竞品池，无需外部爬取即可做竞品分析。
